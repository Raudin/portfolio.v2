# Product Context

## Product Overview
Personal developer portfolio for **Muga Mark**, a Software Engineer specializing in backend and full-stack development (Laravel, Vue, PHP, Python, ML, Nuxt).

## Target Audience
- Technical recruiters, engineering managers, and clients looking for full-stack engineering expertise.
- Visitors seeking to understand Mark's work history, shipped projects, code repositories, and technical competencies.

## Key Value Propositions
- Instant, unambiguous understanding of technical skills and real-world work experience.
- Fast, accessible exploration of featured projects with direct repository links and interface screenshots.
- Direct avenues to contact and connect (Contact, LinkedIn, GitHub).

## Core User Flows
1. **Hero**: Land on site, view headline and current title/focus, navigate via sticky top bar.
2. **Work Experience**: View structured timeline of engineering roles, organizations, tenures, and responsibilities.
3. **Projects Showcase**: Browse key shipped applications, expand details/screenshots/tags on click or keyboard press, and access source code.
4. **Footer**: View current local timestamp and copyright attribution.
